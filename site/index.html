How we test

  1. Picked by handEach mod solves a clear problem, can be installed with one command and has an open-source license.
  2. Pinned and runEvery week, CI checks out the exact commit listed here and runs claude plugin validate and the mod's own tests on the latest Claude Code.
  3. Failures drop outA mod whose tests stop passing leaves the gallery until it passes again.

What this does not prove. It is not a security audit. A passing run means the mod's own tests pass, not that we used every feature by hand. Tokens, network and commands come from the validator's static list of API calls. Screenshots come from the mods' authors. Mods run with your user permissions, so read the source of anything you install.

An independent list, not affiliated with Anthropic. Images belong to the mods' authors; each mod's page links its source and license. Mods marked "Ours" are made by the maintainers of this list.
